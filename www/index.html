IPTV Channel API

v2

API pública de canais IPTV: JSON completo, playlists M3U, player web e proxy HLS que esconde os links originais. Cada canal pode ser aberto pelo número ou pelo nome.

Novidade v2 — URLs por nome: além de /proxy/stream/29/master.m3u8, também funciona /proxy/stream/naturetime/master.m3u8. O proxy é stateless: os segmentos já não dependem de memória do servidor, por isso acabaram os erros intermitentes de segmento.

Canais (JSON)

GET/api/channels?por_pagina=100&pagina=1

Lista paginada de canais (máx. 100 por página). Resposta: {data, meta}. Cada canal traz stream_url (por número) e stream_url_nome (por nome).

GET/api/channels/{id-ou-nome}

Um canal pelo número ou pelo nome (slug). Ex.: /api/channels/29 · /api/channels/naturetime

GET/api/categories

Categorias e quantos canais tem cada uma.

GET/api/search?q=brasil

Pesquisa por nome ou categoria (sem acentos também encontra).

GET/api/stats

Totais: canais, categorias, servidores, com/sem logo. · /api/health — estado e versão da base.

Playlists e player

GET/playlist/all.m3u

Playlist M3U com todos os canais (URLs do proxy, por número).

GET/playlist/{categoria}.m3u

Playlist de uma categoria. Categoria inexistente devolve 404.

GET/player/{id-ou-nome}

Player web do canal (Shaka Player, com fallback HLS nativo). Ex.: /player/naturetime

Proxy HLS

GET/proxy/stream/{id-ou-nome}/master.m3u8

Stream do canal pelo proxy — o link original nunca aparece. Variantes, segmentos, chaves AES e legendas são reescritos pelo mesmo proxy.

GET/proxy/logo/{id-ou-nome}

Logo do canal (redirecciona para o original; sem logo devolve uma imagem transparente 1×1).
